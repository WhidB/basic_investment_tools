# 주식 데이터 Excel 저장 프로그램

Windows용 Python 데스크톱 프로그램입니다. 국내 상장 주식의 이름 또는 종목코드, 시작일·종료일, 일봉·주봉·월봉을 지정하면 `.xlsx` 파일로 저장합니다. Excel 설치 없이도 파일을 만들 수 있습니다.

## 실행

1. Python 3.11 이상을 설치합니다. 설치 옵션에서 **Add Python to PATH**와 **Tcl/Tk**를 활성화하세요.
2. `run.bat`를 더블클릭합니다. 첫 실행은 가상환경과 필요한 패키지를 설치하므로 인터넷 연결이 필요합니다.
3. 종목명(예: 삼성전자, SK하이닉스) 또는 6자리 코드(예: 005930)를 입력합니다.
4. 날짜를 `2025-01-01` 형식으로 입력하고 주기를 선택합니다.
5. **데이터 가져오기 및 Excel 저장**을 누른 뒤 저장 위치를 선택합니다.

직접 실행할 수도 있습니다.

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```

## 저장 내용과 집계 기준

- `주가 데이터`: 실제 기간 시작일·종료일, 시가, 고가, 저가, 종가, 거래량. 날짜/가격/거래량은 Excel에서 정렬·계산할 수 있는 값으로 저장합니다.
- `조회 정보`: 종목, 기간, 통화(KRW), 출처, 저장 시각, 집계 및 가격 기준.
- 종료일까지 포함합니다. 휴장일은 행을 만들지 않습니다.
- 주봉은 월요일~일요일, 월봉은 달력 월 기준입니다. 시가는 첫 거래일, 고가는 최댓값, 저가는 최솟값, 종가는 마지막 거래일, 거래량은 합계입니다.
- 선택 기간에 걸친 첫/마지막 주·월은 **선택 기간 내 거래일만 포함하는 부분 봉**입니다. 오늘을 포함하면 당일 봉도 미완성일 수 있습니다.
- 가격이 0 이하인 행은 거래정지 등의 영향으로 집계를 왜곡할 수 있어 제외합니다. 필수값 누락·중복 날짜가 있으면 오류를 표시합니다.
- NAVER 제공 일별 가격을 사용하며 프로그램에서 별도로 수정주가를 계산하지 않습니다. 제공처의 과거 가격 조정 정책에 영향을 받을 수 있습니다.
- 이름은 현재 KRX 종목 목록에서 정확히 일치하는 종목을 찾습니다. 부분 이름이면 후보를 안내합니다. 상장폐지 종목, ETF 등의 이름 검색은 지원을 보장하지 않습니다.
- 무료 데이터 제공처의 장애·접속 제한·데이터 지연에 따라 조회가 실패할 수 있습니다. 실패 시 임의의 대체 데이터를 만들지 않습니다.

자료: [FinanceDataReader](https://github.com/FinanceData/FinanceDataReader), [NAVER 금융](https://finance.naver.com/).

## 검증

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

테스트는 실제 시세를 가장하지 않는 고정된 테스트 데이터로 날짜 검증, 종목 찾기, 주·월봉 집계 및 Excel 저장을 검증합니다.

개발 환경에서 7개 자동 테스트와 Tk 창 생성 확인을 통과했습니다. 네트워크 패키지 다운로드 지연으로 실제 시세 조회는 검증하지 못했습니다. 첫 실행 시 패키지 설치가 필요하며, 실패하면 연결 상태를 확인한 뒤 `run.bat`를 다시 실행하세요.
