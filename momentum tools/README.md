# Momentum lab

미국 상장 주식·ETF 모멘텀 조회와 전체 시장 필터 도구입니다.

## 실행

환경이 설치된 현재 폴더에서는 **`Start Momentum.bat`를 더블 클릭**하면 기본 브라우저에서 앱이 열립니다. 앱 사용 중 실행 창을 열어두세요. 종료하려면 창에서 Ctrl+C를 누르거나 창을 닫습니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\start.ps1
```

브라우저에서 http://localhost:8501 을 엽니다. 처음에는 **합성 데모 데이터**로 실행됩니다. 실제 시장은 사이드바에서 데모를 끕니다.

사이드바 맨 위 **언어 / Language**에서 **한국어 / English**를 선택할 수 있습니다. 화면의 설정·버튼·공식 해석·결과 안내와 CSV 표시가 바뀝니다. 선택한 언어는 다음 앱 실행에도 유지되며, 저장한 작업에도 포함됩니다. 계산 설정과 결과, 사용자가 지정한 카드 이름은 그대로 유지됩니다. 공식 이름과 티커는 공통 영문 표기를 사용합니다.

기본 **간단히 보기**에서는 공식·티커·필요한 기간과 조건을 먼저 보여줍니다. 카드 이름과 순위 설정, 데이터 설명, 계산 구성값은 펼쳐서 확인합니다. 상대 모멘텀은 **대상 티커**와 **비교 대상 티커**를 각각 입력합니다. 예를 들어 대상=SPY, 비교 대상=TQQQ이면 `M_SPY − M_TQQQ`를 계산하고 두 수익률과 차이(pp)를 함께 표시합니다. 필터에서는 선택 시장의 각 종목을 비교 대상 티커와 비교합니다. 데모에는 이 흐름을 확인할 수 있는 추가 합성 TQQQ 시리즈가 있으며, 전체 스캔 데모 집합은 기존 8종목입니다.

## 사용

1. **값 조회** 또는 **필터**를 선택합니다.
2. 값 조회는 티커 × 공식 카드를 여러 개 추가하고 설정을 적용한 뒤 계산합니다. Multi-Horizon의 각 기간·가중치, MACD 구성값, 회귀 beta·R² 등이 함께 표시됩니다. Cross-sectional/Z-score는 비교집단 티커를 입력하고 조회 종목도 집단에 포함합니다.
3. 필터는 ETF / ETF 제외 / 전체와 누적 / 개별 방식을 선택합니다. 카드별 공식·기간·가중치·벤치마크·통과 조건·순위 방향·순위 가중치를 적용합니다.
4. 누적은 각 공식의 동일 대상 통과 집합을 교집합으로 계산합니다. 개별은 공식별 결과를 모두 보관합니다. 실행을 추가해도 이전 결과는 남습니다.
5. 사이드바 **현재 작업 새로 저장**으로 모든 설정·카드·결과를 SQLite에 저장합니다. 불러오기, 선택 저장본 업데이트/삭제, 실행 업데이트/삭제, 카드 삭제, JSON/CSV 내보내기를 지원합니다.

설정 적용과 실행은 구분됩니다. 화면의 공식 드롭다운을 바꾼 후 **카드 설정 적용**을 눌러야 실행에 반영됩니다. 결과의 실행 업데이트는 그 실행의 저장된 공식을 현재 기준일로 다시 계산합니다. 수정한 공식으로 계산하려면 새 실행을 누릅니다. 저장은 명시적이며, 재시작 전에 저장 버튼을 누르세요.

## 공식과 순위

사용자가 제시한 식을 27개 선택 항목으로 제공합니다. 중복된 Momentum+Downside Volatility는 Downside-Adjusted와 통합했습니다. MA Distance와 MA Momentum은 같은 거리 공식이며 후자는 binary 모드도 지원합니다. 추세의 깨끗함은 R², 방향은 MA 배열, 속도는 beta, 강도는 ADX, 낙폭은 MDD로 제공합니다. Composite Trend Quality는 사용자 가중치의 예시 결합이며 실증적으로 검증된 모델이 아닙니다.

수익률은 계산·표·CSV에서 소수 단위입니다(0.15=15%). 조회 대표값과 필터 기준 입력은 수익률 계열을 %로 표시합니다. 상대 모멘텀은 퍼센트포인트입니다. MACD는 가격 단위입니다. 기간은 거래일이며, EMA/RSI/ADX는 초기값 영향 감소를 위해 추가 관측을 요청합니다.

순위는 기본 큰 값 우선, 작은 값 우선도 선택 가능합니다. Top N은 전체 선택 대상에서 계산하고 동점을 포함합니다. 종합 점수는 각 공식의 유리한 방향에 대한 백분위(0~100)를 사용자 순위 가중치로 평균합니다. 모든 공식에 값이 있는 종목만 종합 점수를 받습니다. 공식이 서로 다른 단위여도 원시값을 직접 더하지 않습니다. 순위는 필터 통과 전 전체 평가 대상 기준입니다.

## 데이터 범위와 한계

[Nasdaq Trader 목록](https://www.nasdaqtrader.com/trader.aspx?id=symboldirdefs)의 Nasdaq 및 otherlisted를 합치고 시험 종목을 제외합니다. ETF는 ETF=Y, 개별 주식 집합은 ETF=N입니다. 비ETF에는 보통주 외 우선주·ADR·워런트·폐쇄형 펀드 등도 포함될 수 있습니다. **OTC, 비상장, 상장폐지 종목은 제외**되며 현재 목록 기반 과거 조회에는 생존편향이 있습니다. 실제 전체 스캔은 일부 대표 티커로 제한하지 않습니다.

[yfinance](https://ranaroussi.github.io/yfinance/index.html)의 auto_adjust=True 일별 OHLC를 사용합니다. 무료 데이터 응답 누락·요청 제한·상장 기간 부족을 포함한 실패를 결과에 공개합니다. 동일 최종 관측일만 비교하며 7일 넘게 오래된 가격은 제외합니다. 벤치마크는 동일 시작/종료 날짜를 요구합니다. 전체 가격·모든 공식 유효 종목 수를 따로 표시하므로 데이터 실패가 필터 탈락과 혼동되지 않습니다. 전체 미국 시장을 100% 수신한다고 보장하지 않습니다. 수천 종목 최초 다운로드는 오래 걸릴 수 있습니다.

일봉의 당일 장중 가격을 피하기 위해 뉴욕의 당일은 제외합니다. 최근 완료된 일봉은 조회일보다 이전일 수 있습니다. 로컬 가격 캐시의 기준일별 CSV와 저장 DB는 `data/`에 보관하며 Git에서 제외합니다. 여러 사용자 인증을 제공하는 공개 서버용 앱이 아닌 로컬 개인 연구 도구입니다.

Hurst는 로그 가격 차분의 블록 R/S 추정이며, VR은 겹치는 단순수익률 합의 표본분산 비율입니다. 통계적 유의성 검정이나 거래 비용·슬리피지를 포함한 백테스트는 수행하지 않습니다. volatility-adjusted의 연율화는 사용자 식대로 분모만 sqrt(252)로 조정하며 Sharpe ratio가 아닙니다.
