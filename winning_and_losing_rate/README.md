# 미국 주식·ETF OHLC 승률 계산기

기간 입력 후 데이터 선택 메뉴가 표시됩니다.

1. **Yahoo**: 온라인으로 가격을 조회합니다.
2. **Investing.com**: 브라우저에서 티커 검색 페이지를 엽니다. 해당 미국 상장 종목의 과거 데이터에서 일별·기간을 선택해 CSV를 다운로드하고, 콘솔에서 Enter를 누른 뒤 파일 선택 창에서 파일을 고릅니다. 자동 다운로드 방식은 아닙니다.
3. **파일 위치**: 이미 내려받은 가격 CSV의 경로를 직접 입력합니다. 따옴표로 감싼 경로도 허용합니다.
0. 이번 계산을 취소합니다.

2번과 3번은 Yahoo에 접속하지 않습니다. 파일 선택을 취소하거나 파일 오류가 발생하면 데이터 선택 메뉴로 돌아갑니다. 파일 선택 창을 열 수 없는 환경에서는 경로를 직접 입력합니다.

Investing.com 영문 열 `Date,Price,Open,High,Low`와 한글 열 `날짜,종가,시가,고가,저가`를 지원하며 `Price`는 종가로 해석합니다. 거래량·변동률은 무시합니다. `YYYY-MM-DD`, `YYYY. MM. DD.`, `YYYY년 MM월 DD일`, 영문 사이트의 `MM/DD/YYYY`, `Jan 02, 2024` 날짜와 천 단위 쉼표 가격을 읽습니다. 영문/한국어 파일 기준이며 소수 쉼표를 사용하는 다른 국가 형식은 지원하지 않습니다. UTF-8과 CP949 인코딩을 지원합니다.

월별·주별 파일을 넣으면 일별 전략 결과가 달라지므로 반드시 일별 파일을 사용하세요. 3번 전체 기간도 파일에 들어 있는 기간만 계산합니다. 기간 제외 기능과 반복 계산도 동일하게 사용할 수 있습니다.

Python 3.10 이상에서 실행합니다.

Windows에서는 **run.bat을 더블 클릭**하면 됩니다. 처음 실행할 때 이 폴더의 `.venv`에 필요한 패키지를 자동 설치하므로 인터넷 연결이 필요합니다. 이후에는 바로 입력 화면이 열리며 결과 확인 후 아무 키나 누르면 창이 닫힙니다. 주가 조회에는 인터넷이 필요합니다.

설치된 Python을 자동으로 찾고, 이 PC에서는 Codex에 포함된 Python도 사용할 수 있습니다. 다른 PC에 옮길 때 Python이 없다면 Python 3.10 이상을 설치하고 `Add python.exe to PATH`를 선택하세요.

터미널에서 직접 실행하려면:

```powershell
python -m pip install -r requirements.txt
python backtest.py
```

미국 상장 주식·ETF 티커(AAPL, MSFT, SPY, QQQ 등), 익절률, 손절률을 입력하고 다음 기간 중 선택합니다.

1. 지정 시작일 ~ 지정 종료일 (양 끝 날짜 포함)
2. 지정 시작일 ~ 현재
3. 상장일부터 ~ 현재: Yahoo Finance가 제공하는 전체 이력. 실제 상장일부터의 데이터가 모두 있다는 보장은 없으며 실제 계산 기간을 출력합니다.
4. 전체 기간에서 지정 기간 제외: 전체 제공 이력에서 제외 시작일·종료일을 포함한 구간을 뺍니다. 예를 들어 2020-01-01 ~ 2020-12-31을 제외하면 그 이전과 이후를 각각 계산해 승리수·패배수를 합산합니다.

4번에서는 제외 기간 전후를 독립적으로 계산합니다. 제외 시작 직전까지 익절·손절하지 못한 포지션은 마지막 포함 거래일 종가로 평가해 미청산으로 기록하며 승패에서 제외합니다. 제외 종료일 이후 첫 거래일 종가에 새로 진입합니다. 제외 기간에 걸친 포지션을 이어서 계산하지 않습니다. 실제 포함 구간과 제외 날짜를 결과에 표시하며, 제외 후 거래일이 하나도 없으면 안내합니다. 제외 범위를 바꿔도 전체 기간 가격 캐시를 재사용합니다.

첫 거래일 종가에 매수하고, 익절·손절로 청산하면 다음 거래일 종가에 재매수합니다. 월요일에 청산하면 화요일 종가에 새로 진입합니다. 다음 날이 휴장일이면 다음 개장일 종가에 진입합니다.

매수일 다음 거래일부터 시가(Open), 고가(High), 저가(Low), 종가(Close)를 사용합니다. 100달러에 종가 매수하고 익절 10%, 손절 5%로 설정했다면 다음 기준으로 판정합니다.

1. 시가가 110달러 이상이면 시가에 익절, 95달러 이하이면 시가에 손절합니다. 갭으로 기준 가격을 넘어 시작한 경우도 실제 시가를 청산 가격으로 사용합니다.
2. 시가가 두 기준 사이이면 고가가 110달러 이상일 때 110달러에 익절, 저가가 95달러 이하일 때 95달러에 손절한 것으로 가정합니다.
3. 같은 날 고가·저가가 두 기준에 모두 도달하면 일봉으로 도달 순서를 알 수 없어 **손절 우선**으로 처리합니다. 해당 거래 수와 CSV 판정 사유에 표시합니다. 시가에서 이미 청산된 경우는 시가 판정이 우선입니다.
4. 어느 기준에도 도달하지 않으면 계속 보유합니다. 기간 종료 시 미청산 거래는 마지막 종가로 평가하며 승률·패율에서 제외합니다.

종가에 매수하므로 매수 당일의 고가·저가는 청산 판정에 사용하지 않습니다. 장중 기준 가격에 체결된다는 가정이며, 실제 체결 순서·슬리피지·유동성은 일봉으로 확인할 수 없습니다.

- 승률 = 승리수 / (승리수 + 패배수) × 100
- 패율 = 패배수 / (승리수 + 패배수) × 100
- 기간 종료까지 미도달한 거래는 미청산으로 표시하고 위 비율에서 제외합니다. 청산이 없으면 비율은 계산 불가입니다.
- 휴장일은 건너뜁니다. 미국 뉴욕 시간 18시 전에는 당일 데이터를 제외하여 진행 중인 일봉을 피합니다. 가격 제공 지연에 따라 최종 데이터일은 더 과거일 수 있습니다.
- `auto_adjust=False`의 `Open`, `High`, `Low`, `Close`를 사용합니다. Yahoo의 과거 가격은 주식분할을 반영하며 배당을 포함하는 수정종가(Adj Close)와 다릅니다. 배당·수수료·세금은 계산하지 않습니다. OHLC 누락이나 잘못된 가격 범위는 오류로 처리합니다.
- 미국 거래소에 상장된 개별 주식과 ETF를 허용합니다. 데이터 제공 실패, 잘못된 티커, 가격 없는 기간은 오류를 출력합니다.

CSV 경로를 입력하면 매수일, 매수종가, 청산일/최종관측일, 청산가격/평가종가, 결과, 수익률, 판정 사유를 저장합니다.

계산 후 **Enter 또는 1**을 누르면 새 종목과 조건으로 계속 계산할 수 있습니다. **0**을 입력하면 종료합니다. 조회나 저장에 오류가 발생해도 같은 메뉴에서 다시 시작할 수 있습니다. Ctrl+C로도 종료할 수 있습니다.

요청 제한(`Too Many Requests`)을 줄이기 위해 별도 종목 정보 조회 대신 가격 조회의 메타데이터로 미국 상장 여부를 검증합니다. 같은 종목·기간의 성공한 조회는 `.price_cache`에 저장해 뉴욕 현지 당일 동안 재사용합니다. 익절·손절률을 바꿔도 가격은 다시 조회하지 않습니다. 날짜가 바뀌거나 기간이 바뀌면 새로 조회합니다. 캐시 폴더를 지우면 다시 조회합니다.

요청 제한 시 10초, 30초 간격으로 최대 두 번 재시도합니다. 그래도 제한되면 한국어 안내 후 반복 메뉴로 돌아갑니다. 제공처의 제한 자체를 즉시 해제할 수는 없으며, 첫 조회가 실패한 경우 저장된 데이터도 없습니다. 이전 날짜의 캐시를 최신 데이터처럼 사용하지 않습니다.

## Yahoo 요청 제한이 계속될 때

재시도나 프로그램 재시작으로 서버의 제한을 해제할 수는 없습니다. `raise_errors`의 폐기 경고는 최신 라이브러리 설정으로 수정했습니다. 최신 라이브러리에서는 해당 경고 없이 오류를 처리합니다.

데이터 선택 메뉴에서 2번 또는 3번을 선택하면 Yahoo 조회 없이 계산합니다. Yahoo 요청 제한이 계속되면 같은 메뉴로 돌아와 다른 데이터를 선택할 수 있습니다. 증권사나 가격 제공처에서 해당 티커의 **일별 OHLC**를 내려받아 사용하세요. 프로그램이 저장하는 거래 결과 CSV는 가격 입력 파일이 아닙니다.

파일에는 `Date,Open,High,Low,Close` 열이 필요하며 날짜 형식은 `YYYY-MM-DD`입니다. 추가 열은 무시하지만 `Symbol` 열이 있으면 입력한 티커와 일치하는지 확인합니다. 역순 날짜는 정렬하며 중복 날짜·잘못된 가격은 거부합니다. 파일에 포함된 실제 기간만 계산하므로 전체 이력 파일인지 확인하세요. 모든 OHLC는 같은 분할 조정 기준이어야 합니다. CSV 입력에서는 미국 상장 여부와 누락된 거래일을 자동 확인하지 않습니다.
