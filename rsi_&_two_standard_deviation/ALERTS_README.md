# 로그인 후 종가 알림

## 등록
1. RSI.bat 또는 Z-score.bat을 실행합니다.
2. 종목과 계산 조건을 입력한 뒤 **알림받기(인터넷)** 또는 **알림받기(VPN)**를 누릅니다.
3. 다음 Windows 로그인부터 인터넷이 연결되면 최신 확정 종가로 계산한 별도 Windows 알림창이 열립니다.
4. 바로 확인하려면 **알림 목록 / 해제 → 지금 알림 확인**을 누릅니다.

예:
- RSI 창: SOXL, 기간 14 → 알림받기
- Z-score 창: TQQQ, 표준편차 2, '몇 년·개월·일 전 ~ 최신 종가', 0년 3개월 0일 → 알림받기

프로그램을 꺼도 등록 상태는 남습니다. 예시 조건은 자동 등록하지 않습니다.
같은 조건을 다시 등록하면 중복 알림을 만들지 않습니다.
수정하려면 목록에서 **설정 불러와 수정** 후 조건을 변경하고 **알림받기(인터넷)** 또는 **알림받기(VPN)**를 누릅니다.
추가 알림으로 전환하려면 **새 알림으로 전환**을 누릅니다.
일반 저장 데이터 수정과 알림 조건 수정은 별개입니다.

## 계산
- 알림은 장중 가격이 아닌 **최신 정규장 확정 종가**를 비교 가격으로 사용합니다.
- 주말·휴장일에는 직전 마감 거래일 종가를 사용합니다.
- 상대 기간은 매번 최신 확정 종가 날짜 기준으로 다시 계산합니다.
- 특정 시작일~최신 종가 방식은 시작일을 유지하고 종료일을 갱신합니다.
- 특정 시작일~특정 종료일은 분석 구간을 그대로 유지하며 최신 종가를 그 구간 통계와 비교합니다.
- 거래일 방식은 기존과 같이 1년=252일, 1개월=21일이며, N일 전까지 최신 종가 포함 N+1개입니다.
- RSI 계산 방식은 기존 프로그램과 동일한 단순 평균 방식입니다.
- Z-score 결과에는 평균, 표준편차, 평균±nσ 가격 범위, 종가의 Z-score와 범위 안/밖, 평균 대비 달러·퍼센트 차이가 표시됩니다.
- 사용 종가 날짜와 조회 시각을 표시합니다. 아직 최신 마감 데이터가 제공되지 않았으면 오래된 결과를 최신으로 표시하지 않고 재시도합니다.

## 자동 시작과 재시도
현재 Windows 사용자의 Run 레지스트리에 알림 프로그램 하나만 등록합니다.
관리자 권한은 필요하지 않습니다. 로그인 전에는 창을 띄울 수 없으므로 '컴퓨터 켜기'는 Windows 로그인 시점 기준입니다.
Windows 시작 프로그램 지연 설정에 따라 실행이 늦어질 수 있습니다.
인터넷 연결 실패는 처음에는 30초 간격, 2분 이후에는 5분 간격으로 재시도합니다. 요청 제한이나 종가 제공 지연은 5분 간격입니다.
성공한 항목은 이번 실행에서 다시 조회하지 않고 실패한 항목만 재시도합니다.
한 로그인 실행 내에서 결과창 하나가 업데이트됩니다. 알림창을 닫으면 이번 대기를 중지하며 다음 로그인 때 다시 시작합니다.
절전 복귀/화면 잠금 해제는 새 로그인으로 간주하지 않습니다.

## 해제와 기록
**알림 목록 / 해제**에서 개별 알림을 해제하거나 전체 자동 알림을 일시정지할 수 있습니다.
마지막 알림을 해제하면 자동 시작 등록도 제거합니다.
최근 결과는 **마지막 결과**에서 다시 볼 수 있으며 30회까지 보관합니다.
등록·결과는 data/alerts.sqlite3에 저장하고 기존 데이터 보관 파일은 그대로 유지합니다.
프로그램 폴더를 옮긴 경우 전용 앱에서 알림받기를 다시 눌러 자동 실행 경로를 갱신하세요.
Windows 작업 관리자의 시작 앱에서 차단했다면 해당 항목도 다시 활성화해야 합니다.

기술 참고: https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys


## 인터넷 / VPN 알림
- 알림받기(인터넷): 기존 동작입니다. 로그인 후 조회하며 연결 실패 시 재시도하고 대기 상태를 표시합니다.
- 알림받기(VPN): 실제 Yahoo 주가 API에서 데이터를 받을 때까지 자동 결과 알림을 띄우지 않고 대기합니다. 보통 30초 간격으로 다시 확인하며, 요청 제한·최신 종가 제공 지연은 5분 간격입니다.
- VPN 클라이언트를 자동으로 켜거나 특정 VPN 어댑터를 감지하지 않습니다. VPN 종류와 무관하게 실제 주가 서버 연결·데이터 수신 성공을 기준으로 합니다. VPN 없이도 서버에 접속되면 계산합니다.
- 아무 웹사이트가 열리는 것만으로 주가 서버 접속이 보장되지 않습니다. 인터넷 방식도 Yahoo 데이터가 필요하며 중국에서 VPN 없이 항상 동작한다고 보장할 수 없습니다.
- VPN 알림만 등록되어 있고 아직 접속되지 않는 경우에는 조용히 대기합니다. 인터넷 알림과 함께 등록했다면 인터넷 결과창에 VPN 대기 개수만 표시하고, VPN 데이터가 준비되면 다시 알려줍니다.
- '지금 알림 확인'은 수동 확인이므로 VPN 미연결 상태에서도 실패/대기 원인을 표시합니다.
- 기존 알림은 인터넷 방식으로 유지됩니다. 목록에서 불러온 뒤 원하는 방식의 버튼을 누르면 해당 알림의 연결 방식을 바꿉니다. 같은 조건을 두 방식으로 각각 등록할 수도 있습니다.
- 표준편차는 2로 고정되지 않습니다. 알림 등록 당시 입력한 1.25, 2, 3.75 등의 값을 저장하고 평균±설정값×표준편차 범위를 계산합니다. 값 수정 후 알림 버튼을 다시 눌러야 등록된 조건이 갱신됩니다.
