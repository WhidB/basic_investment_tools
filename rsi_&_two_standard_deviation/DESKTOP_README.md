# Windows 전용 프로그램
- RSI.bat: 더블클릭하면 RSI 전용 창이 열립니다.
- Z-score.bat: 더블클릭하면 Z-score 전용 창이 열립니다.
- 브라우저나 웹 서버를 실행하지 않습니다. Python/Tkinter 데스크톱 프로그램입니다.
- 현재 폴더의 .venv가 필요합니다. 이 컴퓨터에서는 기존 환경을 사용합니다.
- 인터넷에 연결되어 있어야 주가를 조회할 수 있습니다. USD 미국 주식·ETF만 지원합니다.

## RSI
티커와 RSI 거래일 기간을 입력합니다. 현재 RSI와 최신 확정 종가를 표시합니다.
기존 앱과 같은 최근 N개 변화량의 단순 평균 RSI입니다. Wilder 평활 RSI와 다를 수 있습니다.
주말·휴장일과 아직 마감하지 않은 당일 종가는 제외합니다.

## Z-score 기간 (5가지)
1. 지정 시작일 ~ 지정 종료일
2. 지정 시작일 ~ 최신 확정 종가
3. 상장일 ~ 최신 확정 종가 (제공처에서 조회 가능한 전체 데이터)
4. 상장일 ~ 최신 확정 종가에서 지정 구간 제외
5. 몇 년·개월·일 전 ~ 최신 확정 종가 (기존 방식)

날짜는 YYYY-MM-DD 형식입니다. 구간의 양 끝을 포함하며 제외 구간도 양 끝을 제외합니다.
상장일과 제공처 최초 데이터 날짜가 다를 수 있어 실제 사용 구간을 결과에 표시합니다.
평균과 모집단 표준편차는 선택한 종가로만 계산합니다. 현재 비교 시세는 제외 구간과 관계없이 최근 시세입니다.
|Z-score| <= n 이면 범위 안이며, 표준편차가 0이면 판정할 수 없습니다.
현재 시세가 없으면 최신 확정 종가로 대체하고 출처·시각을 표시합니다.
과거 구간을 선택해도 현재 가격을 비교합니다.

## 저장
데스크톱 전용 data/desktop.sqlite3에 저장합니다. 기존 웹 앱 저장 데이터는 그대로 유지됩니다. 이름을 입력하고 새로 저장합니다.
목록에서 불러온 뒤 조건을 바꾸고 조회·업데이트하면 덮어씁니다.
입력을 바꾼 뒤 조회하지 않고 저장하면 조건만 저장합니다.
상장·제외 방식의 항목은 새 데스크톱 프로그램에서 이용하세요.



## 추가: 거래일 기준 기간
여섯 번째 옵션에서 년·개월·거래일을 입력합니다. 1년=252거래일, 1개월=21거래일로 환산합니다. 최신 확정 종가에서 N거래일 전까지 양 끝을 포함하므로 7일이면 종가 8개입니다. 0년 0개월 7일로 입력하세요. 종가가 부족하면 임의로 짧게 계산하지 않고 오류를 표시합니다. 기존 달력 기간 방식은 그대로 유지됩니다.
