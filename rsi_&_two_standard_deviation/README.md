# RSI · Z-score 주식 분석

미국 주식·ETF의 거래일 종가를 분석하고 조건과 조회 결과를 SQLite에 보관하는 로컬 Streamlit 앱입니다.

## 실행

설치된 이 컴퓨터에서는 **`start.bat`을 더블클릭**하면 앱이 실행되고 기본 브라우저가 자동으로 열립니다. 실행 중에는 검은색 실행 창을 열어 두세요. 창을 닫으면 앱이 종료됩니다.

Python 3.10 이상에서 프로젝트 폴더를 열고 실행합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

이미 설치한 환경에서는 `./run.ps1`을 실행해도 됩니다.

## 사용법

Z-score 기간은 세 방식 중 선택합니다: **몇 년·개월·일 전부터 최신 종가까지**, **지정 시작일~지정 종료일**(예: 2017-10-15~2020-12-30), **지정 시작일부터 최신 종가까지**(예: 2018-05-09부터). 양 끝 날짜를 포함하되 주말·휴장일은 제외하며, 최소 2개 종가가 필요합니다. 과거 구간을 선택해도 비교 대상은 현재 가격입니다. 기간 방식과 날짜도 함께 저장·불러오기·수정할 수 있습니다.

1. RSI 또는 Z-score를 선택합니다.
2. 주식 티커, 기간, 기준 수치를 입력합니다. RSI 예: TQQQ / 14거래일 / <= / 30. Z-score 예: TQQQ / 1년 2개월 3일 / 2σ.
3. **분석 / 최신 데이터 조회**를 누릅니다.
4. 저장 이름을 입력하고 **새로 저장**합니다. 조건만 저장하는 것도 가능합니다.
5. 왼쪽 목록에서 항목을 선택해 **불러오기**한 뒤 입력을 바꾸고 **선택 항목 업데이트**합니다. **삭제**도 가능합니다.

`data/conditions.sqlite3`에는 조건과 마지막으로 조회한 결과·사용 종가·시세 시각이 함께 저장됩니다. 재실행 후에도 유지되며, 파일을 복사하면 백업할 수 있습니다. 불러온 결과는 과거 스냅샷입니다. 최신 조회 후 업데이트해야 저장 데이터도 갱신됩니다. 설정 변경 후 조회하지 않고 저장하면 이전 설정의 결과는 저장하지 않습니다.

## 계산 기준

- 미국 거래소 정규장 마감 시각이 지난 실제 종가만 사용합니다. 주말, 증시 휴장일, 조기 폐장, 서머타임을 NYSE 캘린더로 처리합니다. 빈 날짜를 채워 넣지 않습니다. 연방 공휴일과 증시 휴장일은 다를 수 있습니다.
- RSI: 사용자가 지정한 최근 N거래일의 변화량을 정확히 사용합니다. 종가 N+1개에서 상승분·하락분의 단순 평균으로 `100 - 100/(1 + 평균상승/평균하락)`를 계산합니다. 이는 Wilder 초기 RSI 계산과 같지만, 과거 전체를 재귀적으로 평활하는 Wilder RSI와는 다를 수 있습니다. 변동이 전혀 없으면 50, 상승만 있으면 100, 하락만 있으면 0입니다.
- RSI 결과에는 주가와 RSI 변화 그래프를 각각 표시합니다. 각 날짜의 RSI는 그 날짜까지 N거래일 변화만 사용하며, 그래프 계산용 이전 종가를 추가 조회합니다. RSI 축은 0~100이고 입력한 기준값은 점선입니다. 그래프 데이터도 함께 저장됩니다. 이전 저장 결과에 과거 RSI가 없으면 마지막 값만 표시하며, 최신 조회 후 업데이트하면 전체 그래프가 저장됩니다.
- Z-score 기간: 최신 확정 종가 날짜에서 입력한 년·개월을 먼저 빼고 일을 뺀 날짜까지입니다. 양 끝 날짜를 포함하고 주말·휴장일 데이터는 제외합니다. 없는 날짜는 해당 월 말일로 맞춥니다(2024-03-31에서 1개월 전 = 2024-02-29). 종가가 최소 2개 필요합니다. 조회 결과에 요청 구간과 실제 이용 구간·종가 개수를 표시합니다. 상장일 등으로 이용 가능한 데이터가 짧으면 실제 제공된 구간만 사용합니다.
- Z-score: 선택 구간의 확정 종가를 모집단으로 보고 평균과 모집단 표준편차(ddof=0)를 구합니다. `z=(현재가격-평균)/표준편차`. `|z| <= n`이면 범위 안(경계 포함), 그렇지 않으면 범위 밖입니다. 평균과 상·하단 및 종가 차트를 표시합니다. 표준편차가 0이면 Z-score와 판정은 계산 불가입니다.
- 기존에 저장한 Z-score 거래일 조건은 그대로 불러옵니다. 화면의 **년·개월·일 방식으로 변경**을 누른 후 원하는 기간을 입력하고 업데이트하면 새 방식으로 저장됩니다.
- Z-score 현재가격은 Yahoo 최근 정규장 시세입니다. 지연될 수 있으며 제공되지 않으면 최신 확정 종가로 대체합니다. 출처·시각을 화면에 표시합니다.
- Yahoo 공개 차트 API의 Close를 사용합니다. 배당 조정 종가가 아니며 제공처의 분할 조정은 적용될 수 있습니다. 종가와 최신 시세를 한 번에 조회하여 기존 yfinance의 추가 인증 요청 중 발생하던 제한 오류를 줄였습니다. 같은 종목·기간의 조회 결과와 오류는 5분간 재사용하며, 기준 수치만 바꾸면 추가 요청하지 않습니다. HTTP 429 발생 시 즉시 재시도하지 않습니다. 데이터 부족·오류는 화면에 표시하고, 최근 거래일 데이터가 누락되면 경고합니다.
